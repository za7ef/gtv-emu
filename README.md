# gtv-emu

محاكي مبنيّ من الصفر لمعمارية AArch64 (ARMv8-A)، هدفه تشغيل نظام Android TV / Google TV على أجهزة آيفون.
النواة مكتوبة بلغة C قابلة للنقل، فتُختبر على لينكس ثم تُدمج لاحقًا في تطبيق iOS بواجهة SwiftUI وعرض عبر Metal.

## الحالة الحالية: المراحل الأولى والثانية والثالثة تعمل

يُقلع المحاكي نواة لينكس حقيقية (Alpine linux-virt 6.12 لمعمارية arm64) مع initramfs حتى سطر أوامر busybox تفاعلي،
ويقرأ ويكتب على قرص virtio، ويُطفئ النظام عبر PSCI.

المكوّنات المنفّذة:

- **المعالج:** مفسّر لتعليمات A64 في المستويين EL0 وEL1: العمليات الحسابية والمنطقية، والفروع، والتحميل والتخزين بكل أنماط العنونة، والتعليمات الحصرية، ومسجلات النظام.
- **النقطة العائمة وNEON:** العمليات القياسية والمتجهية الأكثر استخدامًا.
- **وحدة إدارة الذاكرة:** جداول صفحات بحجم 4 كيلوبايت وعناوين 48 بت، مع TTBR0/TTBR1 وTBI والصلاحيات وعلم الوصول، وذاكرة ترجمة مؤقتة (TLB) برمجية.
- **الاستثناءات والمقاطعات:** الاستثناءات المتزامنة وSVC وIRQ وERET.
- **GICv3:** الموزّع والموزّع الفرعي وواجهة المعالج عبر مسجلات النظام.
- **المؤقت العام:** المؤقت الافتراضي والفيزيائي مع WFI موفّر للطاقة.
- **PL011:** منفذ تسلسلي مع مقاطعات للإرسال والاستقبال.
- **virtio-mmio:** ناقل عام بالإصدار الثاني من الواجهة، عليه قرص (virtio-blk) وشبكة (virtio-net) ورسوميات ثنائية الأبعاد (virtio-gpu) ولوحة مفاتيح (virtio-input) وصوت (virtio-snd)، مع شبكة NAT داخلية.
- **تعدد المعالجات:** حتى أربعة معالجات افتراضية عبر PSCI. التفاصيل في [docs/DEVICES.md](docs/DEVICES.md).
- **شجرة الأجهزة (FDT):** تُبنى برمجيًا دون أدوات خارجية.

- **المترجم الفوري (JIT):** ترجمة A64 إلى A64 بكتل أساسية مع ربط مباشر ومسار سريع للذاكرة، ويعمل تلقائيًا على مضيف ARM64. التفاصيل في [docs/JIT.md](docs/JIT.md).

السرعة الحالية للمفسّر: نحو 90 إلى 130 مليون تعليمة في الثانية على معالج x86 حديث، ويصل الإقلاع إلى سطر الأوامر خلال ست ثوانٍ تقريبًا.

## البناء

</div>

```sh
CC=cc ./build.sh          # أو: CC="zig cc" ./build.sh
./tests/boot_test.sh      # اختبار الإقلاع الكامل
cc -O1 -o unit tests/unit_test.c core/simd.c core/devices.c core/virtio.c core/netstack.c core/fdt.c core/jit.c -lm && ./unit
# على مضيف x86 يمكن تجربة JIT عبر qemu-aarch64:
#   CC="zig cc -target aarch64-linux-musl -static" ./build.sh
#   EMU_WRAP=qemu-aarch64 ./tests/boot_test.sh
```

## التشغيل اليدوي

</div>

```sh
./gtv-emu -k Image -i initrd.gz -d disk.img -m 512
```

<div dir="rtl">

| الخيار | الوصف |
|---|---|
| `-k` | ملف النواة بصيغة Image لمعمارية arm64 |
| `-i` | ملف initramfs |
| `-d` | صورة قرص تُعرض كجهاز virtio-blk |
| `-m` | حجم الذاكرة بالميغابايت |
| `-a` | معاملات الإقلاع |
| `--feed` | نص يُكتب آليًا في المنفذ التسلسلي، ويُستخدم في الاختبارات (`\002` ينتظر موجه الصدفة) |
| `--keys` | نص يُكتب عبر لوحة مفاتيح virtio بعد الأمر `\003` في `--feed` |
| `--screenshot` | حفظ الإطار المعروض من virtio-gpu في ملف PNG عند التوقف |
| `--audio` | حفظ صوت virtio-snd في ملف WAV |
| `--smp` | عدد المعالجات (من 1 إلى 4) |
| `--no-jit` | تعطيل المترجم الفوري والعمل بالمفسّر وحده |
| `-v` | رسائل تشخيصية، وتكرارها يزيد التفصيل |

## هيكل المستودع

- `core/cpu.c`: المفسّر ووحدة إدارة الذاكرة ومسجلات النظام والاستثناءات.
- `core/simd.c`: النقطة العائمة وAdvanced SIMD.
- `core/devices.c`: GICv3 والمؤقت وPL011.
- `core/virtio.c`: ناقل virtio-mmio وأجهزة القرص والشبكة والرسوميات والإدخال والصوت.
- `core/netstack.c`: شبكة المستخدم (NAT) وDHCP وDNS.
- `core/fdt.c`: بناء شجرة الأجهزة.
- `core/jit.c`: المترجم الفوري من A64 إلى A64.
- `core/main.c`: واجهة سطر الأوامر.
- `tools/mkinitramfs.py`: بناء initramfs دون أداة cpio.
- `tests/`: اختبارات الوحدة واختبار الإقلاع.
- `docs/ROADMAP.md`: خطة المراحل التالية.
- `docs/JIT.md`: تصميم المترجم الفوري ووضع JIT على iOS والقياسات.
- `docs/ci-workflow.yml`: ملف التكامل المستمر، ويُنقل يدويًا إلى `.github/workflows/`.
